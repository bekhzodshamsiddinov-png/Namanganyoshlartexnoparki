# Namangan yoshlar texnoparki — Innovatsion takliflar

Namangan yoshlar texnoparki faoliyatini rivojlantirish bo‘yicha 30 ta innovatsion taklifning interaktiv taqdimot-sayti (UZ / RU / EN).

- 13 slayd: kirish, mundarija, hozirgi holat va yechimlar, 7 yo‘nalish (30 taklif), yo‘l xaritasi, KPI, yakun
- Klaviatura: ← → (slaydlar), ↑ ↓ (yo‘nalish ichida takliflar), G (barcha slaydlar), Home/End
- Til: `?lang=uz|ru|en`, slayd: `#1`…`#13`
- Mobil qurilmada slaydlar vertikal sahifaga aylanadi

## Ishga tushirish

```bash
npm install
npm run dev     # lokal
npm run build   # dist/ ga yig‘ish
```

Kontent: `src/i18n/uz.json`, `ru.json`, `en.json`. Stek: Vite, React, TypeScript, Tailwind CSS.
